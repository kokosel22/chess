# Chess Coach Overlay

Русскоязычный Android-тренер для стандартных партий с компьютерными ботами официального приложения Chess.com. Android 13+ / ARM64, включая Redmi 12. Kotlin, Android SDK, локальный Stockfish 17.1. Root, подписка и интернет для анализа не требуются. Разрешения INTERNET в приложении нет.

## Скачать APK, ничего не устанавливая на компьютер

1. Войдите в GitHub и откройте [Actions → Android APK](https://github.com/kokosel22/chess/actions/workflows/android.yml).
2. Откройте последний запуск с зелёной галочкой.
3. Прокрутите до **Artifacts**, нажмите **ChessCoachOverlay-Redmi12-debug**.
4. Распакуйте ZIP. Установочный файл: **ChessCoachOverlay-arm64-debug.apk**. Передайте его на телефон и откройте.

В ZIP также входят инструкция, контрольная сумма, исходники приложения и полный исходный код включённого Stockfish вместе с NNUE. Артефакт хранится 30 дней; после истечения срока запустите **Run workflow**. Запуск доступен владельцу репозитория. Подробная инструкция: [INSTALL-RU.md](INSTALL-RU.md).

**Статус проверки:** см. последний успешный запуск Actions. Наличие исходного кода не означает прохождения сборки. Проверка с установленным официальным Chess.com на физическом Redmi 12 требует этого устройства; облачный эмулятор выполняет перечисленные ниже автоматические проверки.

## Что реализовано

- MediaProjection с новым системным согласием для каждого сеанса, foreground service с уведомлением и остановкой. Обработка отзыва разрешения, блокировки, изменения ориентации и очистка ресурсов.
- Поиск клетчатой доски, локальное сравнение 12 фигур с шаблонами Neo, определение ориентации в начальной позиции. Два одинаковых кадра перед изменением состояния. Скриншоты не записываются на диск.
- Стандартные шахматы: легальные ходы с проверкой шаха, рокировка, взятие на проходе, четыре превращения, SAN, FEN со всеми шестью полями, мат, пат, повторения и счётчик ходов.
- Новая партия синхронизируется с начальной расстановки. Пропущенный быстрый ответ бота восстанавливается только при единственном легальном пути из двух полуходов. Нелегальные или неоднозначные кадры не изменяют состояние партии.
- Локальный Stockfish 17.1 через UCI: ARM64 для телефона и x86_64 для эмулятора, 2 потока, Hash 32 MB, ограниченное время на позицию. NNUE включена в нативный файл. Проверка FEN перед каждым анализом и легальности ответа.
- Прозрачный оверлей с оценкой белых и стрелкой в режиме «Подсказки». Касания проходят к доске. При съёмке стрелка временно скрывается для исключения попадания в распознавание.
- «Тренер»: анализирует потери после вашего хода; предварительные варианты и оценка не показываются. «Разбор»: запись без живых подсказок, отчёт после остановки.
- Атомарное сохранение после каждого распознанного хода; полный повторный анализ сохранённой партии, PGN и текстовый отчёт через системное сохранение файлов. Непроанализированные ходы явно отмечены.

## Ограничения распознавания и защиты

Это независимое приложение без доступа к внутреннему состоянию Chess.com. Проверка режима читает дерево специальных возможностей Android. Для включения движка нужны одновременно пакет `com.chess`, найденная доска и явная метка `Bot` / `Computer` / `Бот` / `Компьютер` в области соперника над доской. Признаки онлайн-игры блокируют анализ. Меню «Боты», имя известного бота или простое подтверждение пользователя не считаются доказательством.

**Если текущая версия Chess.com не раскрывает такую метку, подсказки останутся заблокированы.** Поддержка её текущего интерфейса должна быть проверена на телефоне. Система работает консервативно, однако абсолютное определение типа соперника по чужому интерфейсу не гарантируется. Запрещено использовать приложение против людей. Обход проверки не предусмотрен.

Поддерживаются стандартные 2D-фигуры **Neo**, новая стандартная партия с первого хода, полный захват экрана. Произвольные темы фигур, Chess960, середина уже начатой партии, несколько одновременно показанных досок и произвольные перестановки не поддерживаются. Анимация и метки поверх фигур могут снижать уверенность; при сомнении анализ скрывается. После изменения ориентации захват нужно запустить заново. Результат сдачи или соглашения о ничьей по расположению фигур определить нельзя: неполная партия сохраняется с `*`.

## Сборка исключительно в GitHub Actions

Workflow [.github/workflows/android.yml](.github/workflows/android.yml) запускается при каждом push в `main`, для pull request в `main` и вручную. Java 17, Gradle 8.10.2, SDK 35 и NDK устанавливаются только на облачный Ubuntu runner. На компьютере пользователя ничего собирать и устанавливать не нужно. Gradle установлен действием `setup-gradle`; локальная установка и локальный Gradle wrapper намеренно не требуются.

Проверки: JUnit perft начальной позиции и Kiwipete, специальные правила, недостоверные FEN, восстановление партии и блокировка подсказок. Android 35 эмулятор проверяет запуск встроенного Stockfish, матовый ход, распознавание синтетических досок обеих ориентаций, сохранение PGN/отчёта и запуск русского интерфейса. Это автоматические интеграционные тесты; они не заменяют тест MediaProjection поверх реального Chess.com и MIUI/HyperOS.

Каждый успешный этап сборки публикует ARM64 APK, независимо от последующего результата эмулятора. Пользователю рекомендуется выбирать запуск, где успешно прошли и сборка, и тесты. APK подписан debug-ключом, сохраняемым в GitHub Actions Cache. Это установочная тестовая сборка. При удалении кэша подпись может измениться: потребуется удалить предыдущую версию с потерей локальных партий, предварительно экспортировав PGN.
